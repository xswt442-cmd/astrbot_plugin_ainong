# 术语表

本文件只定义词，不描述实现。

## 身份与凭据

**Bot 用户**
向机器人发消息的人。在 QQ 上是一串 QQ 号，在微信上是一串 wxid。同一个人在不同平台是两个Bot 用户，各自有独立绑定。Bot 用户是插件唯一能拿到的、来自消息平台的身份。

**营地账号**
王者营地体系里的账号，用一串数字标识（营地 ID）。由微信或 QQ 扫码登录换取，是营地接口的鉴权主体。一个 Bot 用户绑定一个营地账号。

**游戏角色**
营地账号下的一个具体游戏角色，含大区与区服维度。同一营地账号下可以有多个游戏角色，例如QQ 区与微信区各一个。用户查询时需要指定用哪个角色。

**游戏角色 ID**
营地接口用来标识单个游戏角色的字段。它与游戏内个人主页显示的数字ID 不是同一个东西，不可混用。

**凭据**
让插件以某个营地账号身份调用营地接口的一组值，包括令牌与对称密钥。凭据属于营地账号，不属于 Bot 用户，也不属于游戏角色。

**绑定**
把一个 Bot 用户与一个营地账号关联起来的记录。解绑会删除这条记录及其凭据。

## 数据

**战绩列表**
某个游戏角色近期对局的概要数据，每场包含模式、时间、所用英雄、胜负与评分。一次查询返回多页，单页固定条数，靠游标翻页。

**战绩详情**
单场对局的完整数据，含双方十名玩家的表现、经济曲线等。

**玩家画像**
由战绩列表与详情统计得出的描述，包含段位、常用位置与英雄、胜率、评分倾向等。

## 平台

**浏览器服务**
独立于 AstrBot 容器运行、提供浏览器会话的进程。插件通过它完成扫码登录，不在AstrBot 容器内装浏览器。
