# 爱农

查王者营地战绩，让模型替你锐评。

AstrBot 插件。绑定自己的王者营地账号后，用自然语言问它就能拿到段位、
战绩、英雄池，由对话模型做锐评和玩家画像。

## 它做什么

- 用户扫码绑定自己的营地账号，一个账号下可有多个游戏角色，可切换
- 查询段位、近期战绩、英雄使用情况
- 把统计结果交给模型，让模型给出一段有话说的评价
- 换绑、解绑，凭据与查询记录隔离

## 不做什么

- 不查询他人账号。每个人只能读到自己授权的那个营地账号
- 不做实时对局监控。营地接口有频控，批量拉取既慢也会触发风控
- 不渲染战报图片。输出是给模型读的结构化文本

## 安装

把仓库放进 AstrBot 的 `data/plugins/` 目录，重启或重载插件。

需要 Python 3.10 以上。AstrBot 会读取 `requirements.txt` 自动装依赖。

## 配置

在 AstrBot 面板的插件配置里：

| 配置项 | 说明 |
|---|---|
| 浏览器服务地址 | QQ 扫码需要一个真实浏览器会话。留空则不提供 QQ 扫码 |
| 扫码超时 | 从二维码发出开始计时，超时关闭浏览器并释放资源 |
| 最大并发扫码会话数 | 每个会话独占一个浏览器上下文。超过上限直接拒绝，不排队 |

浏览器服务是独立容器，见 `deploy/compose.playwright.yaml`。微信扫码不需要它。

## 使用

```
/绑定            扫码绑定营地账号
/角色            列出该账号下的游戏角色并切换
/战绩            最近战绩
/段位            当前段位与巅峰分
/解绑            解除绑定并删除凭据
/锐评            让模型基于近期战绩给一段评价
```

也可以直接用自然语言问，模型会调用本插件提供的工具。

## 部署

浏览器服务见 `deploy/`：

- `compose.playwright.yaml` —— 浏览器服务的 compose 片段，不暴露宿主机端口
- `seccomp-profile.json` —— 浏览器容器的 syscall 白名单

内存较小的机器上把最大并发扫码会话数设为 1：一个 Chromium 会话常驻
300-500 MiB，超出会被内核杀掉。

## 开发

```sh
uv sync --group qq-verify   # 装依赖，qq-verify 组提供浏览器连接能力
uv run pytest               # 跑测试
uv run ruff check .
```

`requirements.txt` 是交给 AstrBot 装进容器的依赖清单，由 `uv export` 生成，
不要手工编辑。

QQ 扫码的可行性验证：

```sh
PLAYWRIGHT_SERVER=http://127.0.0.1:3000 uv run python -m ainong.verify.qq_login
```

这条命令会在本地保存一张二维码图片，扫描后打印每一步的结果。

## 数据来源

本插件通过王者营地的接口读取数据。腾讯没有开放面向第三方的玩家数据接口，
这里用的是营地客户端自己的接口，调用方式见 `ainong/camp/`。

营地账号可以设置战绩是否对外展示。对方关闭时查询会失败，插件会说明原因，
不做绕过。

数据仅用于个人查询。请勿用于批量抓取。
